# 小说写作规范与自动导航

当接到撰写新章节的请求时，请严格遵守以下工作流流程：

1. **查阅大纲**：先读取 `03_plot/` 文件夹里对应卷宗的大纲文件，确保新章节的情节与总体规划一致。
2. **遵守设定**：如果有新的人物或产业出现，请查阅或更新 `01_research/` 与 `02_world/人物设定.md`。
3. **语言风格**：保持使用写实的“马伯庸式微观历史”风格撰写正文，强调时代感、金融逻辑与底层小人物在权力与金钱夹缝中的挣扎与反击。
4. **【强制】追加章节导航**：全文输出完毕后，务必在上一章的正文文件（`04_drafts/*.md`）的最末尾追加一个空行，然后添加指向这一章的相对路径 Markdown 超链接。
   * 格式示例：`[下一章：大藏省的审核迷宫](./010_大藏省的审核迷宫.md)`
