# 势力与人物设定（截至第四卷）

## 核心势力：金泽第一百三十国立银行（武士银行）
代表着在明治维新大潮中被抛弃的底层武士，试图通过西式账本和现代金融规则，实现阶级救赎的"草根财阀雏形"。

### 1. 柴田辰之助（行长 / 头取）
* **定位**：前加贺藩理财小吏（御算用者），被同僚嘲笑只懂打算盘不拔刀的驼背武士。
* **性格**：极其冷酷的实用主义者，对数字、复利有着狂热的直觉。
* **弧光**：从第一卷那个为了给兄弟买米而去县厅钻政策漏洞的绝望小人物，进化成了现在手握十万日元存款、敢于用"票据贴现"和"期货对冲"跟东京大财阀正面叫板的冷血银行家。他的经典台词是："拯救穷武士的慈悲游戏结束了，现在银行的齿轮必须咬住血肉才能转动。"
* **外观设定（初期：25-28岁）**：
    *   **气质**：面色苍白，带着由于长期饥饿和焦虑产生的紧缩感。
    *   **发型**：旧式的下级武士发髻（丁髷），且由于疏于打理显得毛糙。
    *   **服饰**：一件已经洗得发白、下摆打着补丁的破旧棉布和服（浴衣）。腰间没有武士刀，而是挂着一把廉价的旧算盘。
    *   **姿态**：弯腰缩颈（驼背），走起路来总是贴着墙根，躲避那些佩刀同僚的鄙视。
* **外观设定（后期：40岁巅峰期）**：
    *   **面部**：面容清瘦，颧骨略高。眼神如“铁算珠”般漆黑、深邃，透着手术刀般的精确与寒意。
    *   **发型**：短发“散切头”，稳重但常因熬夜略显乱。
    *   **眼镜**：银色细边圆框眼镜，象征着其现代金融实战者的身份。
    *   **服饰**：内着深色考究和服（黒纹付），外披一件黑色羊毛大氅（Inverness Cape / 蜻蜓大衣），整体呈现出一种旧士族权威与新资本逻辑交织的压迫感。
    *   **姿态**：双肩微耸，如同俯冲前的猎鹰。
    *   **标志物**：一把磨损圆润的高级煤竹算盘（其权杖与武器）。

### 2. 高桥（安保头目 / 催收队长）
* **定位**：脾气火爆的传统剑客，原本极其鄙视商人。
* **弧光**：被辰之助用"一万日元"赎买后，渐渐放下了武士的傲骨，成为了130银行最忠实的狂热信徒。在第23章坏账危机中，他骨子里的封建高利贷/抄家思维暴露，但被辰之助用现代金融思维强行镇压并洗礼。

### 3. 前田左卫门（副行长 / 门庭护卫）
* **定位**：前太守府的高级护卫武士，极其注重名节。
* **弧光**：为了一百多个兄弟的生计，屈尊降贵给一个"算盘吏"打工。他代表着旧武士阶层最后的尊严和向新时代的低头。
* **股东结构说明**：前田本人出资12,000日元（以金禄公债折算），另有**约50名**旧家臣跟随他一同以各自名义的秩禄公债入股，是为【普通表决股】持有者集团。这50人是前田"一百多个兄弟"中有资格将秩禄公债转为股本的壮丁部分（其余人为家眷、老弱，不在股东名册内）。因此130银行创立时的正式股东总数约为**81人**：底层穷苦武士30人 + 前田系家臣50人 + 前田本人1人。庄兵卫至第29章（第四卷）才正式署名入册。

### 4. 庄兵卫（和泉屋大掌柜 / 实质创始股东）
* **定位**：和泉屋第五代当家，金泽最老牌的生丝与米粮大商人。精明内敛，重利轻义，自称"做了三十年正经生意"。
* **股东身份三阶段**：
    * **第6章（实质入股）**：辰之助以"入股后和泉屋跨区汇款只收极低手续费"为筹码打动庄兵卫，后者承诺注入**一万日元现洋**作为银行设立的全部现金资本金。这是銀行唯一能通过大藏省资金来源审查的硬通货。因此庄兵卫从一开始就是银行真正意义上的**创始最大股东**。
    * **第16章（刻意匿名）**：银行开业时，庄兵卫虽然出了绝大部分资本，却**刻意没有挂名为正式股东**（原文："他需要避嫌，以免别人说商人吞了武士的钱"）。他以幕后出资人身份默默参与，不干预银行的日常决策。
    * **第29章（正式署名）**：挤兑风暴后，庄兵卫作为合作答应的条件，要求将"和泉屋"公开写入股东名册。这是性质的升格——从匿名出资人变为公开背书的共同经营者，以百年老字号信誉公开为银行担保。
* **功能**：银行内连接"武士逻辑"与"商业现实"的缓冲带。他的逆向豪赌（用骡车装大米冒充现洋、敲锣打鼓逆着挤兑人流存钱）是第四卷最大的逆转高光时刻。
* **外观设定**：
    *   **面部**：面色红润且微圆，总是带着一种和蔼的、典型的商业社交微笑，但笑意不达眼底。眼神中偶尔闪过的精光显示出其老练的一面。
    *   **服饰**：极尽奢华的金泽绸缎和服，腰间挂着精致的印笼（药盒）。
    *   **标志物**：手里常握着一杆做工精美的翡翠烟嘴长烟袋（说话间会以此作为节奏点敲打桌面）。

### 5. 柴田桔梗
* **定位**：辰之助的妹妹，武士阶层底层女性的缩影。
* **作用**：当掉母亲和服换取15日元，成为了银行最感人的第一笔"天使投资"。第20章辰之助赎回和服，是对她苦难的彻底终结。
* **外观设定**：
    *   **面部**：五官清秀但不柔弱，眉宇间流露出一股从苦难中生长出来的韧劲。
    *   **发型**：简洁端庄的束发，没有任何多余装饰，体现其干练。
    *   **服饰**：虽然是旧式的细棉和服，但浆洗得异常干净。后期（银行稳定后）衣着开始偏向知性、带有淡淡的管理者气质。

### 6. 伊藤 圭介（洋务书生 / 银行技术顾问）
* **定位**：和泉屋大掌柜庄兵卫挖掘的洋务人才，庆应义塾旁听生。
* **性格**：善良、热血，但技术上限不高。他在第一卷中帮助辰之助理解“折现率”和初步的复式记账。
* **功能**：作为辰之助初期的“西学向导”。在后续的金融危机中，他在技术层面协助银行建立初步的复式记账体系，是银行从传统钱庄转型为现代化银行的重要桥梁。



### 8. 佐藤叔叔（最初的信徒 / 牺牲与宽容的锚点）
* **定位**：金泽基层老武士，辰之助创业初期最早的追随者。
* **性格**：木讷、正直，代表着士族中那批对复杂金融一窍不通、但对“同袍义理”有着绝对信仰的群体。
* **关键事件**：
    * **第一卷**：在全城观运时，他连银行定款（章程）都没看，二话不说就上缴了全家的秩禄公债，是130银行得以设立的第一颗“原始信用基石”。
    * **第五卷**：在坏账大清洗中，他因为经营不善成为死账处理对象。辰之助亲手没收了他视若生命的祖传佩刀。
* **弧光**：他是辰之助“亏欠感”的源头。但在卷末，他用一句“你替我做赚了（换回了全家死路后的生机）”消解了主角的负罪感，通过个体的宽容完成了对“金融逻辑”的最终和解。
* **外观设定**：
    *   **面部**：面容饱经风霜，皱纹里刻满了正气和武士特有的木讷。
    *   **身材**：宽阔的肩膀（曾经持刀的力量感依然在），但现在显得略微沉重。
    *   **空缺感**：腰间少了武士刀后的那种不协调感（其性格中牺牲感的视觉来源）。

## 敌对势力：东京大财阀与官僚（新时代的吞噬者）
代表着明治维新真正的既得利益者，拥有国家机器背书和无限现金流的巨鳄。

### 1. 神田书记官（中枢金融官僚）
* **定位**：大藏省派驻地方的审计官，明治国家金融体系的冷酷“清道夫”。
* **手段**：精通《国立银行条例》与地方法律，视法律为整合散乱资本、强国强兵的精密工具。他与三井等顶级大财阀深度绑定，在第二、三卷中以毁灭主角为表象，实质在进行全国范围内的资本并合实验。
* **核心哲学（金融统制派）**：深信为了让明治日本在西方金本位与关税不平等的碾压中生存，国家必须拥有 **“一个大脑（中央银行）”** 与 **“几根主动脉（大财阀）”**。他视地方性的、由旧武士组成的 130 银行为金融系统中的“低效脓肿”和“潜在叛乱中心”，必须通过合法的行政压力将其强行并入国家大循环。
* **真实属性**：虽是辰之助的死对头，但在宏观逻辑上是明治国家秩序的“冷酷的设计师”。他的每一次致命攻击，实质上都是针对日本金融系统的极高规格“压力测试”。他并非追求个人财富，而是追求大藏省对每一分钱的绝对调度权。
* **外观设定**：
    *   **面部**：神情冷峻，蓄着打理得极其完美的八字胡，五官如同精算的公式般高度对称。
    *   **服饰**：极其合身体的三件套西装，洁净的高领白衬衫及考究的领结。皮鞋锃亮，像大理石雕像一般冰冷入时。
    *   **配饰**：手中常握着一枚大藏省的印章或怀表，象征其作为“系统发明者”的权力。

### 2. 伊藤源（北陆总代办 / 财阀白手套）
* **定位**：神田书记官和三井财阀在地方上的"大掌柜"。
* **手段**：精通资本垄断与剥削（强行以三折包销金箔）。在第三卷中，他成为辰之助的首要实战对手，狂傲地动用财阀库存，在横滨发动"疯狂倾销（砸盘）"，制造期票坏账，试图从实业端彻底绞杀130银行。
* **外观设定**：
    *   **面部**：中年男子，头发抹着厚厚的发油向后梳，眼神中透着一股商人特有的计算与油滑。
    *   **服饰**：虽然穿着西式服装，但总是喜欢戴几枚夸张的玉石戒指，这种中西合璧的土豪感显示了其地方土生土长但依附财阀的背景。

## 被压迫的实业基石（客户与拯救对象）

### 1. 吉左卫门（金箔工坊老坊主）
* **定位**：金泽传承百年的金箔工匠。
* **作用**：大日本帝国最顶尖手艺与最底层奴役悲剧的结合体。被财阀逼得差点上吊（引出银行第一笔坏账），最终成为辰之助利用"产业信贷"和"贴现"进行资本解放的标志性图腾。
* **外观设定**：
    *   **面部**：极度苍老且干瘦，皮肤如褶皱的黄金箔纸。头发花白，常系着一条洗得发白的职人头巾（钵卷）。
    *   **手部**：指关节因长期劳作而变形，但握紧工具时依然极稳。

### 2. 村上教官（生丝厂厂长）
* **定位**：被大藏省"士族授产"官方骗局套牢的退役老兵。
* **作用**：验证了银行异地汇票跨越物理押运的神奇魔力，击碎了本地黑帮（松井）的高利贷系统。
* **外观设定**：
    *   **气质**：时刻保持着僵硬的军人坐姿，脊背挺得笔直。
    *   **服饰**：常穿着一套略显陈旧、洗得发白的旧式陆军军服。面部有一道西南战争时期留下的浅浅伤疤。
