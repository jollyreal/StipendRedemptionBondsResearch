# 小说时间线（《秩禄公债》）

> 本时间线对照真实历史事件，标注小说剧情的大致时序。
> 括号内为对应章节编号。

---

## 历史大背景年表

| 历史年份 | 明治年号 | 真实历史事件 |
|:---|:---|:---|
| 1869 | 明治2年 | 废藩置县预备期，加贺藩（金泽）管辖权开始动摇 |
| 1871 | 明治4年 | 废藩置县正式实施，全国武士阶级俸禄改由政府统一支付 |
| 1873 | 明治6年 | 地租改正（全国农商税制大改革）开始推行 |
| 1875 | 明治8年 | 《国立银行条例》第一版颁布，民间申请开设银行潮兴起 |
| **1876** | **明治9年** | **《秩禄处分》——政府强制以「金禄公债」一次性买断全国武士俸禄（小说核心起点）** |
| 1876.5 | 明治9年 | 《国立银行条例》修订案颁布，允许以金禄公债充当80%资本金开设国立银行 |
| 1876.10 | 明治9年 | 神风连之乱（熊本）、秋月之乱（福冈）、萩之乱（山口）——九州武士武装反抗政府 |
| **1877.2** | **明治10年** | **西南战争爆发（西乡隆盛举旗）——政府大规模印钞，通货膨胀开始加速（第五卷背景）** |
| 1877.9 | 明治10年 | 西南战争终结，西乡隆盛败亡 |
| 1878.5 | 明治11年 | **纪尾井坂之变**：大久保利通被刺。政府权力版图重组，向**伊藤博文**与**大隈重信**倾斜。 |
| 1878 | 明治11年 | 《株式取引所条例》颁布，**东京、大阪证券交易所**成立，通胀投机进入非理性狂热期。 |
| 1880.2 | 明治13年 | **佐野常民**接手财政，大隈重信提出的五千万外债方案被内部极力否决，派系斗争达到顶点。 |
| 1881.10 | 明治14年 | **明治十四年政变**：大隈重信下野。**松方正义**正式出任大藏卿，开启强硬紧缩政策（松方财政）。 |
| 1882 | 明治15年 | 日本银行创立，宣告民间银行发行纸币特许权进入“死缓期”。 |
| 1885 | 明治18年 | 银本位制确立，「松方通缩」达到顶峰 |

## 小说剧情时间线

### 第一卷：算盘与废纸（起点）
**时间：明治9年（1876年）夏～秋**

| 章节 | 剧情摘要 |
|:---|:---|
| Ch 01《激荡的前夕》 | 金泽县厅外大排长龙，武士们领取金禄公债证书。辰之助把公债藏入内衬，开始思考应对之策。 |
| Ch 02《算盘上的道义》 | 长町武士聚会，高桥等人讨论是否将公债三折卖给高利贷。辰之助首次登场并阻止。 |
| Ch 03《街头抢筹战》 | 辰之助开始游说其他武士，桔梗当掉母亲的和服换来15日元作为最初的行动资金。 |
| Ch 04《台账里的硕鼠》 | 发现高利贷和官吏勾结操纵账目，初步确立反制的思路。 |
| Ch 05《叩开旧时代的大门》 | 辰之助在废旧条例中发现「可用公债充当80%银行资本金」的漏洞，构思开设国立银行的大计。 |

### 第二卷：定款之战（筹备期）
**时间：明治9年（1876年）秋**

| 章节 | 剧情摘要 |
|:---|:---|
| Ch 06《一万日元的死锁》 | 拜访和泉屋庄兵卫，以汇兑优惠为筹码，换取一万日元现金入股。 |
| Ch 07《算盘兵团的诞生》 | 彻夜核查庄兵卫的历年账册，为应对神田的天书账单做准备。 |
| Ch 08《账本上的宣判》 | 与神田书记官正面交锋，用复式记账法反将一军，保住庄兵卫的资产。 |
| Ch 09《长町的月见节》 | 阶段性小胜后的短暂喘息，武士们在月见节聚餐，庄兵卫带酒肉庆祝。 |
| Ch 10《大藏省的审核迷宫》 | 赴东京大藏省申请开业特许，遭遇层层刁难。 |
| Ch 11《折现率的密码》 | 解开大藏省设下的西洋财务考题，争取到关键的利率核定通过。 |
| Ch 12《复式阵法与一万日元的家谱》 | 用复式账本证明庄兵卫的一万日元是自有资金而非过桥借款，通过大藏省资金来源审查。 |
| Ch 12a《外传：算盘与十字阵的布道》 | 番外：辰之助向武士们讲解复式记账法的运作原理。 |
| Ch 13《平权法案里的毒刺》 | 与财阀律师斗法，解决股东内部的「优先股 vs 普通股」利益分配危机。 |
| Ch 14《长町的黑夜与访客》 | 深夜博弈，辰之助在前田的尊严、庄兵卫的现金流和三十武士的饭碗之间，设计出「收益优先股」的折中方案。 |
| Ch 15《定款里的杀阵》 | 与反对派律师的最终对决，依法锁死定款条文，确保银行的「刚性分红」架构成立。 |
| Ch 16《第130国立银行的诞生》 | 明治9年深秋，金泽第一百三十国立银行于和泉屋旧米仓正式开业挂牌。 |

### 第三卷：第一桶金与商战
**时间：明治9年（1876年）秋末**

| 章节 | 剧情摘要 |
|:---|:---|
| Ch 17《纸币的枷锁与零业务死局》 | 开业后零业务，揭示「刚性7%分红」带来的死亡压力。 |
| Ch 18《跨越山海的汇票》 | 生丝老兵村上陷入长野采购危机。辰之助引入异地见票即付银行汇票（Banker's Draft）。 |
| Ch 19《不要拔刀的复仇》 | 电报汇票绝杀，在高利贷松井逼债现场完成金融反杀，第一笔跨区利润入账。 |
| Ch 19a《外传：清算之网与九州的血》 | 番外：高桥看到九州镇压新闻，辰之助解释「往来联行清算网络（Correspondent Banking）」的逻辑。 |

### 第三卷：商战高潮（砸盘与坏账）
**时间：明治9年（1876年）初冬**

| 章节 | 剧情摘要 |
|:---|:---|
| Ch 20《赎回的和服与碎银子》 | 存款狂潮涌入，辰之助用第一笔薪水赎回桔梗的母亲和服。 |
| Ch 21《金箔的泣血与东京的影子》 | 目睹金箔工匠被财阀剥削，辰之助决定介入产业信贷。 |
| Ch 22《票据的魔法与东京的怒火》 | 向金泽十八家金箔工坊提供票据贴现（Discounting），财阀代理人伊藤源登门威胁砸盘。 |
| Ch 23《致命的倾销与第一笔坏账》 | 伊藤源在横滨疯狂砸盘，导致承销商破产，银行遭遇第一笔巨额坏账。武士内部差点走上逼债抄家的老路。 |
| Ch 24《算盘上的血战》 | 辰之助阻止抄家，带队进入大宗商品期货市场对冲，用做空财阀资产弥补坏账窟窿。 |

### 第四卷：挤兑风暴（生存保卫战）
**时间：明治9年（1876年）初冬**

| 章节 | 剧情摘要 |
|:---|:---|
| Ch 25-27 | （第三卷金箔业大获全胜收尾，神田开始策划挤兑攻势） |
| Ch 28《庄兵卫的逆向豪赌》 | 挤兑风暴爆发高潮。庄兵卫驾骡车敲锣逆行注资，逆转人心，挤兑瓦解。 |
| Ch 29《废墟上的新王》 | 门关后清点仅剩178块现洋，庄兵卫的装米骗局被识破。大藏省发来三日审计限令。辰之助启动三日补洞计划，庄兵卫开出正式署名条件，两人握手成交。 |
