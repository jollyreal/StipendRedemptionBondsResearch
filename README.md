# 秩禄公债物语：历史小说创作项目

欢迎使用 Antigravity 辅助小说创作框架！这是一个专为历史小说创作设计的文件夹结构，旨在帮助你有条理地进行研究、设定、大纲规划和正文撰写。

## 项目结构
- `01_research/`：存放历史背景研究、资料收集和参考链接。
- `02_world/`：存放人物小传和世界观背景。
- `03_plot/`：存放故事大纲、章节规划。
- `04_drafts/`：存放小说正文草稿。
- `05_prompts/`：存放与 Antigravity 交互的提示词模板。

## 创作主题：秩禄公债（日本明治初期的秩禄处分）
本小说旨在通过故事的形式，深入浅出地探讨日本明治维新时期，政府发行“金禄公债”（即秩禄公债）以废除武士阶级世袭俸禄的历史事件，以及这一政策对当时社会（特别是武士阶层）带来的巨大冲击。
