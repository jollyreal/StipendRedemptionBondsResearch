## 为什么选这个主题
会开始写这部小说是因为昨天看了这个影片。然后就像我自己对AI的理解的挺多的，也不至于到现在连一个像样的作品也没有。
- [還在羨慕別人用 AI 開發酷產品？Claude Code 保姆級教學讓你輕鬆體驗 Vibe Coding, 動動嘴就能做出 Anything！](https://www.youtube.com/watch?v=2pM-7fBXc_M)

然后我就想到之前看到脑总的影片[金融的底层是武力：为何明治维新能造就财阀，而大清首富只能被割韭菜？](https://www.youtube.com/watch?v=sGyU9XhOJ18),想到说历史中都记载大人物的丰功伟业，但是我更想知道的是那些小人物在那个时代是怎么活下来的。

说到写小人物的生活的话，刚好有一名作家就是以写小人物的生活而闻名的，那就是马伯庸。他最擅长的就是在历史的夹缝中，写出小人物的挣扎求生。而且我最喜欢的点就是他不碰大历史，而是在历史夹缝中找到可以创作的空间。刚巧我自己也刚刚看了他的访谈[马伯庸X脱不花：麻烦你，把话说明白](https://www.dedao.cn/course/article?id=RQLYWyjMZoa0J1vpm5Xp4wvzDbO26B)

# 縁起 (日本語訳)

## なぜこのテーマを選んだのか
この小説を書き始めたきっかけは、昨日この動画を見たからです。自分なりにAIについてはかなり理解しているつもりでしたが、いまだにまともな作品を一つも作れていないことに気づきました。
- [還在羨慕別人用 AI 開發酷產品？Claude Code 保姆級教學讓你輕鬆體驗 Vibe Coding, 動動嘴就能做出 Anything！](https://www.youtube.com/watch?v=2pM-7fBXc_M)

そして、以前見た脳総（脑总）氏の動画[「金融の底流は武力：なぜ明治維新は財閥を生み出し、大清の首富は搾取されるだけだったのか？」](https://www.youtube.com/watch?v=sGyU9XhOJ18)を思い出し、歴史には偉人の功績ばかりが記されていますが、当時の「小人物（庶民や下級武士）」たちがどのように生き抜いたのかをより深く知りたいと思いました。

「小人物」の生活を描くといえば、まさにその分野で有名な作家がいます。馬伯庸氏です。彼は歴史の隙間で、名もなき人々が生き残るために葛藤する姿を描くのが非常に巧みです。私が最も好きなのは、彼が大文字の「歴史（正史）」に触れるのではなく、歴史の隙間に創作の空間を見出す点です。ちょうど彼のインタビュー動画[「馬伯庸 X 脱不花：お願いだから、話をはっきりさせて」](https://www.dedao.cn/course/article?id=RQLYWyjMZoa0J1vpm5Xp4wvzDbO26B)も見たばかりでした。
