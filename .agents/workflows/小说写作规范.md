# 小说写作规范：分阶段协同工作流

当接到撰写新章节的请求时，请严格遵守以下【三阶段】流程：

## 1. 策划阶段：逻辑与细纲（Proposal Phase）
在开始正式描写前，AI 必须先输出以下内容并获取用户确认：
1.  **查阅内核与设定**：确认已读取 `02_world/创作内核与叙事控制点.md` 和 `02_world/人物设定.md`。
2.  **核心冲突要点（The Hook）**：本章要解决什么核心矛盾（内在 vs 外在）？
3.  **金融与历史逻辑（Financial/Historical Logic）**：本章涉及哪些真实的金融工具或历史背景？逻辑是否通顺？
4.  **关键转折点（Key Beats）**：列出 3-5 个推动剧情发展的关键场景。

**注：输出完成后停顿，等待用户回复“批准执行”或提出修改建议。**

## 2. 撰写阶段：正文创作（Drafting Phase）
用户批准后，按照细纲进行文学化撰写。
-   **语言风格**：保持“马伯庸式微观历史”风格，侧重器物描写、心理反应与时代感。
-   **技术细节**：将金融公式、会计准则巧妙融入人物对话和冲突中，不要写成教科书。
-   **内核嵌入**：确保“赢的代价”和“大趋势”这些控制点在正文中有具体体现。

## 3. 整理阶段：红队自检与导航（Refining Phase）
正文输出完毕后，AI 自动完成以下操作：
1.  **AI 编辑自评报告**：
    -   是否存在现代词汇违和？
    -   金融逻辑和人物行为是否协调？
    -   悬念配置是否合理？
2.  **【强制】追加章节导航**：在上一章的正文文件（`04_drafts/*.md`）末尾追加指向本章的相对路径 Markdown 超链接。
    -   示例：`[下一章：算盘的阵痛](./030_算盘的阵痛.md)`
