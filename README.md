# 《秩禄公债》：旧血与新钞的算盘对决

> **当旧武士拔刀斩向新时代，却发现永远也砍不断“资本复利”的枷锁。**
> 在明治维新的宏大叙事背后，是一场用纸笔和算盘谋杀了四十万武士阶层的沉默绞肉机。

## 📖 小说简介 (Synopsis)
**明治九年（1876年），日本政府下达了残酷的“秩禄处分”——彻底废除武士阶级延续数百年的世袭工资，转而发给他们一张名叫【金禄公债】的废纸。**

面对这每年只有固定 5% 或 7% 利息，却根本无法兑换现金的废纸，曾经在战场上威风凛凛的武士们，不得不将它们以二三折的血亏价格贱卖给黑心的高利贷商人，无数人在新时代的寒冬里含恨自尽。

**柴田辰之助**，一个出身于最低级“御算用者（会计武士）”、不仅背有点驼而且只会打算盘的没落小人物，却在这张废纸里看到了政府最冷酷的数学陷阱。他没有拔刀，而是拿起了被武士阶层鄙视了一辈子的账本和算盘。

在这个连西方“公司法”和“复式记账”都如同天书的封建末期乡下：
* **对抗财阀的恶意倾销？** 他不靠间谍或武力，而是坐在账房里，通过研读枯燥的《太政官日誌》与同业报表，剥离出对手隐藏在复杂衍生品下的致命死穴。
* **反击大藏省的合规死扣？** 他用传统的《大福账》精密对接西方“复式记账”，在制度的洪流中，为那些被时代抛弃的武士们，生生算出了一个避风港。

这不是刀光剑影的幕末武侠，而是一场**“系统的力量对抗系统本身”**的硬核金融商战。看一个只会心算的会计，如何整合公开的信息碎片，向那个由精英与财阀编织的现代巨网，发起最无声也最致命的冲锋！
